# Skill 库 · 三维像素书房

- 解压后打开 `dist/index.html`。按住书房画面拖动可以在已建模的角度范围内旋转，底部「查看侧面」可直接切换到侧视角，「复位视角」恢复开场位置。聚焦书房后也可以使用方向键和 Home 键。
- `dist/skill-library-room.glb` 是可编辑模型。可在 Blender 中选择「文件 → 导入 → glTF 2.0」。模型含墙角、地板、家具、摆件、材质及两个参考相机。
- 页面需要支持 WebGL 2 的浏览器。默认画面直接渲染网格，字牌、屏幕和地毯等细节使用程序生成的材质。
- 点击电脑，打开 MCP 工具库选择本地文件。窗下的四门储存柜也能下载 MCP 和 Skill。上传的文件用 IndexedDB 保存于当前浏览器和站点，下载保留文件名和原始内容。旧版本仅保存了资料的条目仍可导出配置或说明。
- 光标悬停或键盘聚焦书架上的书时，书会沿着层板向外抽出。

## 修改源码

模型尺寸和摆放以米为单位，编辑 `build-room.js` 可调整家具与灯光，编辑 `room.js` 可调整网页镜头和交互。安装 Node.js 和依赖后重新构建网页与导出模型。

```sh
npm install
npm run build
npm run export-model
```
